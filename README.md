# Rivals External

## Download & run

1. Unzip it anywhere.
2. Run **`overlay.exe`**. No arguments, any order:
   - launch it before Roblox, after it, or mid-match — it attaches by itself. ( best if you launch while in rivals itself )
   - a status card paints immediately: `waiting for Roblox` → `found - attaching` →
     `reading memory` → `ATTACHED` (fades after 4 s).
   - it detaches and re-cards on a rejoin or game close; a second copy just exits.

`config.ini` sits next to the exe and holds your menu settings plus the learned per-zoom
gain table. It rewrites itself; delete it to reset.

## Controls (live overlay)

| Key | Action |
|-----|--------|
| **INSERT** | toggle the menu (window is clickable while open, click-through otherwise) |
| **END** | quit (**not** Esc — Esc is used in-game) |

- **Column 1 — ESP:** master, Boxes, Names, Health, Snaplines, Snap-from-center. Filters: Hide teammates, Arena filter.
- **Column 2 — Aimbot:** Enable, Head/Torso, Always/Hold/Toggle + key Bind, Closest/Lock, Smoothing, FOV limit + radius, Max distance, Wall check, Dim covered enemies, Draw FOV circle.
